# 北斗定位服务器（ESP32-S3 + ATGM336H-5N）

把 ESP32 做成一台小服务器：读取北斗模块的定位数据，同时在串口和网页上发布出去。
全部代码在 `beidou_gps_test.ino` 里，打开这一个文件就能上传。

ESP32 启动后会自动选择工作方式，无论哪种，网页都能打开：

| 方式 | 触发条件 | 网页地址 |
| --- | --- | --- |
| 接入路由器 | 能连上 WiFi（正常情况） | http://192.168.31.200 |
| 自己开热点 | 连不上路由器时自动兜底 | http://192.168.4.1 |

服务器对外提供两个地址：`/` 是实时刷新的测试页面，`/data` 是 JSON 数据接口，
方便以后接别的程序或做二次开发。

## 一、接线

| 模块引脚 | ESP32-S3 | 说明 |
| --- | --- | --- |
| 5V | 5V | 供电 |
| GND | GND | 必须共地 |
| TX | GPIO17 | 模块发数据，接 ESP32 接收脚 |
| RX | GPIO18 | ESP32 发数据，接模块接收脚 |

接 ESP32 时，模块上的 USB 口不要同时插到电脑，两者是同一路串口，会冲突。
天线要拧到 SMA 口上，放在露天、平面朝天，远离金属。

## 二、WiFi 配置

网络配置在代码顶部，当前用的是温湿度工程里验证过的那个：

| 项目 | 值 |
| --- | --- |
| 名称 SSID | Xiaomi_AE4D |
| 密码 | 123456780 |
| 网段 | 192.168.31.x |
| 网关 | 192.168.31.1 |

小米路由器有两个 WiFi 名字：**不带 `_5G` 的是 2.4GHz，带 `_5G` 的是 5GHz**。
ESP32 只支持 2.4GHz，所以必须用 `Xiaomi_AE4D`。

如果密码不对、连不上路由器，程序会自动切换到热点模式（见下面第三节），
不会一直卡着打不开网页。

## 三、热点兜底模式

路由器连不上时，ESP32 会自己开一个热点：

| 项目 | 值 |
| --- | --- |
| 热点名称 | Beidou-GPS |
| 热点密码 | 12345678 |
| 网页地址 | http://192.168.4.1 |

用法：手机连上 `Beidou-GPS` 这个热点，浏览器打开 http://192.168.4.1 就能看页面。
注意手机连热点时会暂时没有外网，这是正常的，页面本身照常能用。

想关掉这个兜底，把代码顶部的 `#define AP_FALLBACK 1` 改成 `0` 即可。

## 四、在 Arduino IDE 中烧录

1. 安装 ESP32 支持包：开发板管理器搜索 `esp32`，安装 Espressif Systems 的包。
2. 用 Arduino IDE 打开 `beidou_gps_test.ino`。
3. 开发板选择 **ESP32S3 Dev Module**，端口选择 ESP32 对应的串口。
4. 点击上传。若上传失败，按住板上的 BOOT 键再点上传。

程序启动时会自动扫描附近的 WiFi 并把结果打印在串口里，方便确认 SSID 是否正确。

## 五、查看结果

串口监视器：波特率设为 **115200**。每秒打印一次定位数据。

网页：串口连接成功后会直接打印出该用哪个地址，照它打开即可。页面上显示纬度、经度、
海拔、卫星数、HDOP、速度、航向、UTC 与北京时间、天线状态、位姿帧十六进制和原始
GGA 语句，并给出地图链接，每秒自动刷新。

## 六、固定 IP 说明

接入路由器时默认使用固定 IP，网页网址不会每次变：

```
IPAddress STATIC_IP     (192, 168, 31, 200);
IPAddress STATIC_GATEWAY(192, 168, 31, 1);
IPAddress STATIC_SUBNET (255, 255, 255, 0);
IPAddress STATIC_DNS    (192, 168, 31, 1);
```

温湿度工程用的是 192.168.31.100，这里用 200，两台设备不会冲突。
如果换了路由器、网段不是 192.168.31.x，把前三段改成和网关一致即可。

固定 IP 万一连不上，程序会先自动回退成由路由器自动分配；再不行才进入热点模式。
想彻底关掉固定 IP，把顶部的 `#define USE_STATIC_IP 1` 改成 `0`。

## 七、常见问题

- 想去路由器模式却进了热点模式：说明路由器没连上，看串口打印的状态码，1 是找不到网络，4 是密码不对。
- 网页打不开：确认手机或电脑和 ESP32 在同一个网络，地址用 `http://` 开头。
- 串口没有任何定位输出：检查 TX/RX 是否接反、天线是否接好、波特率是否为 9600。
- 有数据但一直未定位：多为天线位置问题，拿到露天空旷处，等 1 到 3 分钟冷启动。
