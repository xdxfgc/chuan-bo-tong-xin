# 船舶终端（ESP32 + 北斗 + 激光测距 + LoRa 信标接收 + 语音播报）

一块板子做四件事：读北斗定位、读激光测距、用 LoRa 收信标坐标、用语音把落水信标的方向和距离喊出来，
同时把这些数据发布到网页上。全部代码在 `beidou_gps_test.ino` 里。

工作流程：

信标落水 → 信标（ESP32-C3）用 LoRa 发坐标 → 本板收到并回 ACK
→ 用本船北斗位置算出方向与距离 → SYN6288 语音播报 → OLED/网页同步显示

## 一、接线

北斗定位模块 ATGM336H-5N：

| 模块引脚 | ESP32 | 说明 |
| --- | --- | --- |
| 5V | 5V | 供电 |
| GND | GND | 必须共地 |
| TX | GPIO17 | 模块发数据，接 ESP32 接收脚 |
| RX | GPIO18 | ESP32 发数据，接模块接收脚 |

激光测距模块 VL53L1X（I2C）：

| 模块引脚 | ESP32 | 说明 |
| --- | --- | --- |
| VIN | 3.3V | 只能接 3.3V，接 5V 会烧坏 |
| GND | GND | 必须共地 |
| SCL | GPIO22 | I2C 时钟 |
| SDA | GPIO21 | I2C 数据 |
| GPIO1 / XSHUT | 空着 | 可以不接 |

LoRa 模块 SX1278（Ra-01 / Ra-02，433MHz，SPI）：

| 模块引脚 | ESP32 | 说明 |
| --- | --- | --- |
| VCC | 3.3V | 只能 3.3V |
| GND | GND | 共地 |
| SCK | GPIO14 | SPI 时钟 |
| MISO | GPIO12 | SPI 数据入 |
| MOSI | GPIO13 | SPI 数据出 |
| NSS | GPIO27 | 片选 |
| RST | GPIO32 | 复位 |
| DIO0 | 不接 | 本程序用轮询，不需要中断脚 |

SYN6288 语音模块：

| 模块引脚 | ESP32 | 说明 |
| --- | --- | --- |
| RXD | GPIO16 | 必接，ESP32 发、模块收 |
| TXD | GPIO4 | 可选，接上能看到模块应答 0x41 |
| VCC | 5V | 功放吃电流，5V 声音才够大 |
| GND | GND | 共地 |
| SPK+ / SPK- | 喇叭 | 接小喇叭 |

接 ESP32 时，北斗模块上的 USB 口不要同时插到电脑，两者是同一路串口，会冲突。
北斗天线要拧到 SMA 口上，放在露天、平面朝天，远离金属。

## 二、WiFi 配置

固定 IP，网页地址固定为 **http://192.168.31.200**。相关设置和热点兜底都在代码顶部，
说明见后面几节。

| 项目 | 值 |
| --- | --- |
| SSID | Xiaomi_AE4D |
| 密码 | 123456780 |
| 网段 | 192.168.31.x |

小米路由器有两个 WiFi 名字：**不带 `_5G` 的是 2.4GHz，带 `_5G` 的是 5GHz**。
ESP32 只支持 2.4GHz，必须用 `Xiaomi_AE4D`。

连不上路由器时程序会自动开热点兜底：热点名 `Beidou-GPS`，密码 `12345678`，
网页地址变成 http://192.168.4.1。想关掉兜底，把顶部 `#define AP_FALLBACK 1` 改成 `0`。

## 三、LoRa 通信协议

和信标端（ESP32-C3）约定好的文本协议，两边必须一致：

```
信标 → 本板：  M,<序号>,P,<定位有效 0/1>,<纬度>,<经度>
本板 → 信标：  A,<序号>,C,<本方定位有效 0/1>,<纬度>,<经度>
```

信标每 2 秒发一次；本板收到立刻回 ACK，信标靠它判断这一轮成功。
同一个序号重复到达只回 ACK，不重复播报。

射频参数两端必须完全相同：`433MHz / SF10 / BW125kHz / 同步字 0x12 / 开启 CRC`。

## 四、语音播报

SYN6288 只认 GB2312，不能直接发 UTF-8 中文，所以程序里把要用到的词预先算成字节存起来，
数字和 `[v16]` 音量标记在运行时拼上去。

播报内容形如："人员落水，信标在东北方向，距离约 123 米，坐标北纬 26.2091 度，东经 111.5989 度。"

为避免语音排队，做了节流：两次播报最短间隔 8 秒；目标移动超过 3 米、或方位发生变化、
或超过 20 秒，才重新播报。链路中断超过 15 秒会播报"与信标失去联系"，恢复时播报"通信已恢复"。

音量可以在串口监视器里在线调整：输入 `v0` 到 `v16` 回车（例如 `v10`），立刻生效并播一句"你好"试听。

## 五、在 Arduino IDE 中烧录

1. 安装 ESP32 支持包：开发板管理器搜索 `esp32`，装 Espressif Systems 的包。
2. 用 Arduino IDE 打开 `beidou_gps_test.ino`。
3. 开发板按实际硬件选 **ESP32 Dev Module** 或 **ESP32S3 Dev Module**（两种都已验证能编译）。
4. 端口选 ESP32 对应的串口，点上传。失败时按住板上 BOOT 键再上传。

用到的三个库都已经装在这台电脑的 Arduino 库里：

| 库 | 版本 | 用途 |
| --- | --- | --- |
| VL53L1X | 1.3.1（Pololu） | 激光测距 |
| LoRa | 0.8.0（sandeepmistry） | SX1278 收发 |
| Wire / SPI | 随 ESP32 核心 | I2C 与 SPI |

换电脑时在库管理器里搜 `VL53L1X` 和 `LoRa` 各装一个即可。

## 六、查看结果

串口监视器波特率 **115200**。每秒打印两块内容：北斗定位与激光测距的状态，以及信标链路状态
（在线与否、RSSI、信标坐标、搜索引导的方向和距离）。

网页地址 **http://192.168.31.200**，页面上有定位、激光距离和信标三组卡片。
收到有效信标坐标时，页面顶部的横幅会变成红色的落水提示，显示方向和距离。

## 七、常见问题

- LoRa 初始化失败：检查 3.3V 供电、SPI 五根线，尤其是模块是不是 Ra-01/Ra-02 的 433MHz 版本。
- 收不到信标：确认信标端的频率/SF/带宽/同步字和本板完全一致，天线接好。
- 语音不响：确认模块供电是 5V、喇叭接在 SPK+/SPK-、串口是 GPIO16 接模块 RXD。
- 网页打不开：确认手机或电脑和 ESP32 在同一网络，地址用 `http://` 开头。
