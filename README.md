# chuan-bo-tong-xin

通导一体化水上安全终端 —— **三端**：船端（移动终端）、信标（可穿戴）、岸基节点（港口）。

## 目录结构

```
chuan-bo-tong-xin/
├─ beidou_gps_test/     船端（移动终端）   ESP32 DevKit
├─ C3_Coord_Sender/     信标（可穿戴）     ESP32-C3 SuperMini
└─ shore_base_node/     岸基节点（港口）   ESP32 DevKit
```

三端用**同一套 433MHz LoRa 参数**和**同一套文本协议**，可以两两互通。
接线在船端和岸基是刻意做成一样的（同样五个模块），便于对测和维护。

## 一、三端各干什么

| 设备 | 角色 | 硬件 |
| --- | --- | --- |
| **船端** | 移动终端 | ESP32 + 北斗 + 激光测距 + MPU6050 + 磁力计 + OLED + LoRa + 语音 + 蜂鸣器 |
| **信标** | 可穿戴（救生衣） | ESP32-C3 + LoRa + 北斗 + 水感电极 + MPU6050 |
| **岸基** | 参考站（码头） | ESP32 + 北斗 + 激光测距 + OLED + LoRa + 语音 |

**三项安全功能：**

- **落水搜救** —— 信标落水自动激活上报 → 船端和岸基同时告警、算方位距离、语音播报
- **靠泊辅助** —— 激光测距 + 分级告警（0x01/0x02/0x03）+ 靠妥判定；远处用北斗算"距岸基"
- **走锚监测** —— 基准位置 + 位移超限 + 漂移趋势（0x21/0x22）

## 二、三端协议

前缀区分角色，**第 2 个字段统一是发送者编号**：

```
信标 -> 所有： M,<信标ID>,<序号>,P,<定位有效 0/1>,<纬度>,<经度>
船端 -> 所有： S,<船ID>,<序号>,P,<定位有效 0/1>,<纬度>,<经度>,
                 <对地速度节>,<航向度>,<卫星数>
岸基 -> 所有： R,<岸基ID>,<序号>,P,<岸基定位有效 0/1>,<纬度>,<经度>
应答 -> 对方： A,<自己ID>,<序号>,C,<自己定位有效 0/1>,<纬度>,<经度>
```

**设备编号**（三端必须各不相同，在各自 `config.h` 里改）：

| 设备 | 编号 |
| --- | --- |
| 船端 | `1` |
| 信标 | `11` / `12` / `13` … |
| 岸基 | `21` / `22` … |

**为什么岸基用 `R` 不用 `S`**：船端已经占了 `S`（本船广播），两个都用 `S`
船端就分不清收到的是船还是岸基。`R` = Reference（参考站）。

**老格式也认**（第 2 个字段直接是序号、没有编号）。
判断办法：**第 3 个字段**直接以 `P` 或 `C` 开头就是老格式 ——
不能用"第 2 个字段是不是数字"判断，两种格式那里都是数字。
这样旧固件也能接进来，不用三端同时换固件。

**射频参数三端必须完全相同**：`433 MHz / SF10 / 125 kHz / 同步字 0x12 / CRC 开`。
只要有一项不同就互相收不到。

## 三、三端怎么互动

```
        信标 (11)
        │  M 帧（落水坐标）
        ├──────────► 船端 (1)：告警 + 播报 + 回 ACK
        │            └── S 帧 ──► 岸基 (21)：显示"距船端 / 船端方位"
        └──────────► 岸基 (21)：告警 + 播报 + 回 ACK
                     └── R 帧 ──► 船端 (1)：显示"距岸基 / 岸基方位"
```

| 场景 | 船端 | 信标 | 岸基 |
| --- | --- | --- | --- |
| 信标落水 | 语音 + 蜂鸣器 + 网页告警 | 三重确认后开始上报 | 语音 + 网页告警 |
| 正常值守 | 每 5 秒广播 S 帧（信标在线时让路） | 静默待机 | 每 2 秒广播 R 帧 |
| 靠近码头 | 显示"距岸基 XX 米" | — | 只跟踪，不播报 |

## 四、开发板与烧录

| 工程 | 开发板 | 端口 |
| --- | --- | --- |
| 船端 | **ESP32 Dev Module** | CH340 那个口 |
| 岸基 | **ESP32 Dev Module** | CH340 那个口 |
| 信标 | **ESP32C3 Dev Module** | `USB 串行设备` 那个口 |

串口监视器统一 **115200**，行尾选「换行」。

⚠ **信标一定要选 `ESP32C3 Dev Module`**，选成 `ESP32 Dev Module` 会报
`'USBCDC' does not name a type`（C3 是 RISC-V，和普通 ESP32 不是一回事）。

**分区方案**：船端程序较大，选 **Huge APP (3MB No OTA/1MB SPIFFS)**。

**加过新文件后**，把 IDE 关掉重新打开一次，让它重新扫描文件列表。
